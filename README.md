# Respaldo de Videos

App de escritorio para Windows que permite a un creador respaldar sus propios videos usando yt-dlp y ffmpeg.

Hecha con Tauri 2 + Vue 3 + TypeScript.

## Desarrollo

```
npm install
npm run tauri dev
```

## Generar el instalador

```
npm run tauri build
```
